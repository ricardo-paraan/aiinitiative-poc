Notice that `ticket_id` is __NOT__ in this INSERT statement, which means Hibernate is not recognizing it as an auto-generated column.

## 🔧 Here's the exact fix:

__Run these SQL commands in your PostgreSQL database:__

```sql
-- Connect to your database
\c aitesting

-- Check current table structure
\d ticket_tbl

-- Drop the table and recreate with SERIAL
DROP TABLE IF EXISTS ticket_attachments_tbl CASCADE;
DROP TABLE IF EXISTS ticket_comments_tbl CASCADE;
DROP TABLE IF EXISTS ticket_tbl CASCADE;

-- Create with SERIAL (auto-increment)
CREATE TABLE ticket_tbl (
    ticket_id SERIAL PRIMARY KEY,
    title VARCHAR(100),
    author VARCHAR(50),
    system_name VARCHAR(50),
    category VARCHAR(50),
    description VARCHAR(1000),
    attachment_id INT,
    status VARCHAR(20),
    comment_id INT,
    created_date DATE,
    update_date DATE
);

-- Recreate dependent tables
CREATE TABLE ticket_attachments_tbl (
    attachment_id SERIAL PRIMARY KEY,
    ticket_id INT,
    file_path VARCHAR(100),
    FOREIGN KEY (ticket_id) REFERENCES ticket_tbl(ticket_id) ON DELETE CASCADE
);

CREATE TABLE ticket_comments_tbl (
    comment_id SERIAL PRIMARY KEY,
    ticket_id INT,
    comments VARCHAR(500),
    FOREIGN KEY (ticket_id) REFERENCES ticket_tbl(ticket_id) ON DELETE CASCADE
);

-- Insert your existing tickets back (if you have backup data)
-- INSERT INTO ticket_tbl (ticket_id, title, author, ...) VALUES ...;

-- Reset the sequence to continue from the highest ID
SELECT setval('ticket_tbl_ticket_id_seq', (SELECT COALESCE(MAX(ticket_id), 0) FROM ticket_tbl) + 1, false);
```

__The key is:__ Your table definition must use `SERIAL` or have a proper DEFAULT on ticket_id:

```sql
ticket_id SERIAL PRIMARY KEY
```

or

```sql
ticket_id INT PRIMARY KEY DEFAULT nextval('ticket_tbl_ticket_id_seq')
```
