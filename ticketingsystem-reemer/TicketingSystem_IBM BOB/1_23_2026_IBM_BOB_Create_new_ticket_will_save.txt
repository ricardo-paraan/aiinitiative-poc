📝 Database Saving Details
The TicketViewController.java createTicket() method:

Receives form data from the HTML form
Automatically sets:
status = "PENDING" (new tickets start as pending)
createdDate = current timestamp
updateDate = current timestamp
attachmentId = 0 (default)

Calls ticketService.saveTicket(ticket) which uses JPA/Hibernate to:
Execute SQL INSERT statement
Save to your PostgreSQL ticket_tbl table
Return the saved ticket with auto-generated ticket_id
Redirects to dashboard with success message
